# Vamsi Bammidi Portfolio Website

A modern and responsive personal portfolio website built using HTML and CSS.
This portfolio showcases projects, skills, resume, and contact information with a professional dark-themed UI design.

## Features

* Modern professional UI
* Responsive design for mobile and desktop
* Animated hover effects
* Glassmorphism project cards
* Smooth navigation
* Resume download/view option
* Projects showcase section
* Skills section
* Contact information section

## Technologies Used

* HTML5
* CSS3
* Responsive Web Design
* Flexbox
* CSS Grid
* Glassmorphism UI Design
